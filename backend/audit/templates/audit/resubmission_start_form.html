Resubmitting an Audit

Resubmission is available to make updates to a previousy submitted report. Resubmission must be completed in coordination between the auditee and certifying officials. Depending on the updates, a resubmitted report may result in a new Federal Audit Clearinghouse (FAC) acceptance date. A resubmission can never change the UEI or the audit year from the original submission.

Before proceeding, review the guidance below to determine the appropriate whether resubmission path. Resubmitted reports with material changes will result in a new FAC acceptance date. Non-material changes to reports will retain the original FAC acceptance date. All resubmission paths allow for updates to the SF-SAC data collection form. The following options are available for resubmission:

  • Material change to a PDF Audit report. This will result in a new FAC acceptance date.
  • Non-material change to a PDF Audit report. This original FAC acceptance date will be retained.
  • Updates to only the SF-SAC data collection form. The original FAC acceptance date will be retained.
